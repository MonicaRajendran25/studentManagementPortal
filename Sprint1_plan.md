# Sprint-1 Plan

## Sprint Details

**Sprint Number:** Sprint 1  
**Duration:** 1 week  
**Sprint Goal:** Develop the initial Student Management Portal interface and implement the basic functionality for adding and viewing student records.

## Sprint Backlog

| Task ID | Task Description | Story Points |
|---|---|---:|
| T01 | Create the project folder and repository structure. | 1 |
| T02 | Design the portal home page. | 2 |
| T03 | Create the student registration form. | 3 |
| T04 | Implement the Add Student functionality. | 3 |
| T05 | Display student records in a table. | 2 |
| T06 | Test the registration form and student list. | 2 |

## Sprint Schedule

**Day 1:** Set up the repository and design the home page.

**Day 2:** Develop the student registration form.

**Day 3:** Implement the Add Student functionality.

**Day 4:** Display student records in a table.

**Day 5:** Test the application, fix defects, and update the documentation.

## Sprint Deliverables
- Student Management Portal home page.
- Student registration form.
- Ability to add student details.
- Student list displayed in a table.
- Tested and documented initial version.

## Acceptance Criteria
1. The registration form accepts the required student details.
2. Required fields are validated.
3. Newly added student records appear in the student list.
4. The application works correctly during basic testing.
5. All completed work is pushed to GitHub.
